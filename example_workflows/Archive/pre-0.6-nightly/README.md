# Previous nightly workflows

These 19 workflows were retained unchanged when nightly adopted the released
0.6 catalog. They are historical examples, not the recommended starting points;
they may contain older widget values, references, and layouts.

Use the [current workflow catalog](../../README.md) for fresh projects.
Reference media remains in [the shared assets folder](../../assets/).

The newer catalog is rebuilt from named 0.6 recipes using nightly's own node
definitions. The archive is never used as input to that builder.
